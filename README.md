# Web and Cloud Security - CS 595

This repository contains my web and cloud security coursework at Portland State University. I wrote Python scripts while working through controlled security labs involving authentication, SQL injection, cross-site scripting (XSS), server-side request forgery (SSRF), cross-site request forgery (CSRF), and access control. I wanted to understand what makes these vulnerabilities possible, not just memorize their names.

For the final project, I focused on four API security labs: exposed API documentation, server-side parameter pollution, an undocumented endpoint, and mass assignment. Each one includes an exploit script and notes on how I tested the issue, checked the result, and considered possible fixes. All testing was done as part of authorized coursework and lab environments.
